# v0.3.32-alpha — 在线更新闪退修复

修复点击「下载并安装」后 KOReader 退出的问题。旧代码校验 GitHub 下载地址时只取了第一段字符串的长度，再与仓库名拼接，将字符串误传给 `string.sub` 的数字参数，下载开始前就会抛异常。

下载文件现在由请求外层统一关闭，避免网络结束回调关闭后，错误处理再次关闭文件。HTTP 错误、连接中断、超时和安装器异常都会显示失败原因；HTTP 200 但传输失败也不会开始安装。

验证：WSL Ubuntu 下 LuaJIT 完整回归 18 组、1976 条断言全部通过；真实 KOReader v2026.07.1 中验证 403 提示和 302 → 200 下载、摘要校验、解压及插件替换，安装后 26 个插件文件与 ZIP 完全一致。此结果不替代 Kindle 真机验证。详见 [验证记录](../../research/update-validation-2026-11-24.md)。

退出 KOReader，将 `inkbridge.moon.koplugin-v0.3.32-alpha.zip` 内的整个 `inkbridge.koplugin/` 覆盖到 `plugins/`，再启动 KOReader。旧版更新器本身存在此缺陷，此次须手动覆盖安装。
