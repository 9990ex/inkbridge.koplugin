# v0.3.33-alpha — 进度选择展示章节和文段

阅读时的「选择要跳转的进度」由图标网格改为无图标纵向文字卡片。每条直接展示时间、设备、真实章节和两行原文选段，不再用冗长文件名占满按钮。

最多只读获取最近三条墨桥记录，按当前书籍完整身份核验，章节取自本机核验位置的目录，选段从匹配的原文向后延展。静读天下记录也通过已有字符坐标还原和正文唯一核验补全；缺失或无法核验的内容明确提示。

列表关闭、窗口变化或切书后，迟到读取结果失效。选择记录仍进入原有位置比较和跳转确认；预览不会上传、删除或自动跳转。保留 0.3.32-alpha 的在线更新修复。

WSL LuaJIT 完整回归 18 组、1993 条断言通过。真实 KOReader 在 605×921 和 420×720 下验证文字卡片、长选段、取消、选择后位置比较及云端不变。见 [验证和截图](../../research/history-list-validation-2026-11-24.md)。
