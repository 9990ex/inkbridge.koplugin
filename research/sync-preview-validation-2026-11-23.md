# 同步前差异预览：WSL 双 KOReader 验证

2026-11-23，在 WSL Ubuntu 中运行两个真实 KOReader 2026.07.1 窗口，使用当前工作树插件、隔离配置和同一本《绍宋》EPUB 副本。A 为 605×921，排出 5891 页；B 为 420×720，排出 5288 页。临时目录为 `/home/nvidia/ib-sync-preview-lab`。

同步经过 KOReader 原生 WebDAV provider 的真实 HTTP PROPFIND、PUT、GET，目标为本机 `127.0.0.1:18765/records`。临时服务器由 Python 标准库提供，仅用于隔离测试；没有连接用户原 WebDAV，也没有测试第三方云端认证。两份 EPUB SHA-256 均为 `553f53a2c5642d6d3f6df9a56015edb4bd218ef7a91f880b324e6100a22aaba7`，与原书一致。

## 结果

| 操作 | 实测结果 |
|---|---|
| B 下载 A 的记录后取消预览 | B 保持 3595/5288 页，xpointer、正文锚点及内容位置不变；WebDAV 文件集合及 SHA-256 不变 |
| A → B，在预览选择跳转 | A 的 2179/5891 页定位至 B 的 1969/5288 页；xpointer 与正文锚点逐字一致 |
| B 在预览选择上传本机 | B 保持 3595/5288 页，新增 Lab-B 记录保存 B 的真实 xpointer 与正文，不先跳转到 A |
| B → A，在预览选择跳转 | B 的 3595/5288 页定位至 A 的 3997/5891 页；xpointer 与正文锚点逐字一致 |
| 下载与跳转是否写云端 | 两个方向的下载、预览和跳转均未改变 WebDAV 文件集合及内容 |
| 常规及窄屏预览 | 两端实际排版均为 14 行，控件容量 18 行，全部可见；显示本机与远端章节、正文、记录时间、比较结果和跳转精度 |

B 使用 X11 鼠标点击实际按钮；A 因 WSL 窗口叠放影响鼠标定位，使用 UIManager 的原生 Gesture/tap 分发，通过按钮触控区域触发原有回调。书籍定位、界面控件与网络接口均为真实运行时，没有用业务桩代替。

分页模式仍将目标正文放到所在页；本次 A → B 的正文在目标页第 25 行，B → A 在第 8 行，预览和跳转后的提示均保留该信息。

## 实测发现并修正

- 原预览使用说明文字的小字号与灰色，字段间多余空行导致比较结论、跳转精度在窄屏被省略。修正为黑色 17 号字、紧凑行距、按屏幕限制的内容高度和两列动作。
- 远端缺少章节时，按已核验的目标 xpointer 从本机目录读取真实章节；只用于展示，不修改云端载荷。
- 时间使用记录载荷中的时间，避免本机测试服务器的 HTTP 时间解析偏移被显示为“8 小时前”。时间仍来自记录设备时钟，不据此断言哪端阅读位置较新。
- 跳转、上传图标明确使用向下、向上箭头；底部显示“取消”。
